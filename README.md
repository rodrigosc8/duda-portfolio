# Duda Terra - Portefólio Criativo 🎨

Um portefólio criativo moderno e responsivo para Maria Eduarda "Duda" Terra, designer gráfica, fotógrafa e criadora de conteúdo.

## 🌟 Características

- **Design Responsivo**: Totalmente otimizado para dispositivos móveis, tablets e desktops
- **Animações Suaves**: Utilizando Framer Motion para transições elegantes
- **Performance Otimizada**: Build otimizado com Vite e CSS Tailwind
- **Acessibilidade**: Componentes semânticos com suporte a navegação por teclado
- **SEO Otimizado**: Meta tags, OpenGraph e títulos descritivos
- **Portfólio Completo**: Showcase de 15+ projetos em diferentes categorias

## 🎯 Secções

- **Hero**: Apresentação inicial com destaques das especialidades
- **Projetos em Destaque**: Visualização de projetos selecionados
- **Sobre**: Biografia e valores criativos
- **Porquê Crio**: Abordagem criativa e filosofia
- **Ferramentas & Interesses**: Tech stack e obsessões criativas
- **Arquivo de Projetos**: Grid filtrável com todos os projetos
- **Contacto**: Links para redes sociais e email

## 🛠️ Stack Tecnológico

- **React 18**: Framework UI
- **Vite**: Build tool ultra-rápido
- **Tailwind CSS**: Utility-first CSS
- **Framer Motion**: Animações e transições
- **PostCSS + Autoprefixer**: Processamento CSS
- **JavaScript (ES6+)**: Lógica da aplicação

## 📁 Estrutura do Projeto

```
src/
├── components/        # Componentes React reutilizáveis
├── data/             # Conteúdo e configurações
├── App.jsx           # Componente raiz
├── index.css         # Estilos globais
└── main.jsx          # Ponto de entrada

public/assets/        # Imagens e recursos estáticos
├── collage/         # Elementos decorativos
├── Portfólio/       # Screenshots de projetos
└── Fotografias/     # Ensaios fotográficos
```

## 🚀 Como Usar

### Instalação

```bash
npm install
```

### Desenvolvimento

```bash
npm run dev
```

Abre [http://localhost:5173](http://localhost:5173) no navegador.

### Build para Produção

```bash
npm run build
```

### Pré-visualização da Build

```bash
npm run preview
```
