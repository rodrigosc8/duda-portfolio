## 🚀 Como Usar Agora

### Desenvolvimento Local
```bash
npm install
npm run dev
```
Abre em http://localhost:5174/

### Build para Produção
```bash
npm run build
```
Gera pasta `dist/` pronta para deployment

### Deploy (Vercel - Recomendado)
```bash
vercel
```
Ou segue instruções em DEPLOYMENT.md
